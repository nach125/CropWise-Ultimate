CROPWISE ULTIMATE — START HERE (Windows)
1. Extract the ZIP.
2. Open this folder (CropWise_Ultimate), the one containing app.py and requirements.txt.
3. Double-click run_windows.bat, OR open CMD in this folder and run:
   python -m pip install -r requirements.txt
   python -m streamlit run app.py
4. Open http://localhost:8501 if the browser does not open.
5. On Train & Compare Models, upload Crop_recommendation.csv and train.
Dataset is not included in ZIP. Source link is in README.md.
